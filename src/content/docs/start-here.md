This site covers the grammar in the **TN State Board Class 11 and Class 12 English** textbooks. Every topic is explained in simple English, with examples, common mistakes and practice questions.

## How the site is organised

- **Foundation refresher:** the basics that every other topic depends on, such as verb forms (V1 to V5) and the parts of a sentence.
- **Grammar topics:** one group per topic. Most topics have a **Class 11** page and a **Class 12** page. The Class 12 page builds on the Class 11 page, so read the Class 11 page first if you need to revise.
- **Quick reference:** one-page tables to check something fast, such as the tense table and the irregular verb list.

The label under each page title shows which class the page belongs to.

## How to search

Click the search bar at the top (on a computer you can also press <kbd>Ctrl</kbd> + <kbd>K</kbd>). You can type:

- a topic: *reported speech*, *passive voice*
- a rule or phrase: *aren't I*, *unless*, *than any other*
- a grammar term: *gerund*, *past participle*, *finite verb*

The results open at the matching part of the page.

## Install it on your phone

The site can be installed like an app. It gets its own icon, opens full-screen, and pages you have already opened work without internet.

**Android (Chrome):** open the site, tap the **⋮** menu, then tap **Install app** (or **Add to Home screen**).

**iPhone (Safari):** open the site, tap the **Share** button, then tap **Add to Home Screen**.

New lessons appear automatically. You do not need to reinstall anything.

## Pages marked "Not yet reviewed"

Every lesson and practice page is complete. Pages with the **Not yet reviewed** label have not yet been checked by a teacher. Once a teacher has checked a page, the label is removed.
