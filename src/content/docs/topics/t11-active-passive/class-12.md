- the rule: object → subject, *be* (same tense) + V3, *by* + agent
- the passive form of every tense (*is done, is being done, has been done, was done...*)
- pronoun changes (*I → me, they → them*)
- that verbs with no object (*arrive, sleep*) have no passive

## What you will learn

- The passive with **modals**: *can be done, must have been done*
- The passive of **questions**:
  - yes/no: *Did he write the letter?* → *Was the letter written by him?*
  - wh-: *Who wrote this?* → *By whom was this written?*
- The passive of **commands and requests**: *Shut the door.* → *Let the door be shut.* / *You are requested to...*
- Verbs with **two objects**: *He gave me a book.* → *I was given a book.* / *A book was given to me.*
- **Agents other than *by***: *known to, interested in, filled with, surprised at*
- The **impersonal passive**: *It is said that...* / *He is said to be...*
- Why **intransitive verbs** have no passive
- **Infinitive and gerund passives**: *to be done*, *being done*

## Why this matters

Class 11 covered statements. Class 12 adds every other kind of sentence: questions, commands, sentences with modals, and sentences with two objects. These are the questions that separate good answers from average ones in the exam.

The impersonal passive (*It is believed that...*) is also very common in newspapers, reports and formal essays.

## The idea in simple words

The basic idea does not change: the **receiver** of the action becomes the subject, and the verb becomes ***be* + V3**.

What changes in Class 12 is the **sentence type**. A question stays a question. A command stays a command. A modal stays the same modal.

> *Active:* ***Can** you **solve** this sum?*
> *Passive:* ***Can** this sum **be solved** by you?*

> *Active:* ***Close** the window.*
> *Passive:* ***Let** the window **be closed**.*

## Grammar words you need

**Modal:** *can, could, may, might, will, would, shall, should, must, ought to*. See [Modal auxiliaries](/topics/t02-modal-auxiliaries/class-11/).

**Imperative sentence:** a command, request or piece of advice: *Shut the door. Please help me.*

**Direct object:** the thing that receives the action: *He gave me **a book**.*

**Indirect object:** the person who receives the direct object: *He gave **me** a book.*

**Impersonal passive:** a passive with *it* as the subject, used to report what people say or think: ***It is said** that...*

**Infinitive:** *to* + V1 (*to do*). **Gerund:** V4 used as a noun (*doing*). See [Non-finite verbs](/topics/t07-non-finite-verbs/class-12/).

## The rules

### Rule 1: With a modal, the passive is modal + *be* + V3.

| Active | Passive |
|---|---|
| *You **can solve** this sum.* | *This sum **can be solved** by you.* |
| *We **must finish** the work today.* | *The work **must be finished** today.* |
| *They **should help** the poor.* | *The poor **should be helped**.* |
| *You **may take** this book.* | *This book **may be taken** by you.* |
| *He **ought to obey** the rules.* | *The rules **ought to be obeyed** by him.* |
| *You **have to wear** a helmet.* | *A helmet **has to be worn**.* |

The modal stays the **same**. Only the main verb changes to *be* + V3.

### Rule 2: With a modal + *have* + V3, the passive is modal + *have been* + V3.

| Active | Passive |
|---|---|
| *Someone **must have stolen** the bag.* | *The bag **must have been stolen**.* |
| *You **should have told** me.* | *I **should have been told**.* |
| *They **might have cancelled** the show.* | *The show **might have been cancelled**.* |
| *He **could have finished** the work.* | *The work **could have been finished** by him.* |

### Rule 3: For a yes/no question, make the passive, then put the first helping verb before the subject.

| Active question | Passive question |
|---|---|
| ***Did** he write the letter?* | ***Was** the letter written by him?* |
| ***Does** she sing Carnatic songs?* | ***Are** Carnatic songs sung by her?* |
| ***Is** Ravi cooking dinner?* | ***Is** dinner being cooked by Ravi?* |
| ***Have** you finished the project?* | ***Has** the project been finished by you?* |
| ***Will** they invite us?* | ***Will** we be invited by them?* |
| ***Can** you lift this box?* | ***Can** this box be lifted by you?* |

**Method:**
1. Turn the question into a statement: *Did he write the letter?* → *He wrote the letter.*
2. Make it passive: *The letter was written by him.*
3. Turn it back into a question: ***Was** the letter written by him?*

The *do / does / did* of the active question disappears. The passive has its own helping verb (*was, are, is...*).

### Rule 4: For a wh- question, keep the question word and follow the same method.

**(a) The question word is not the subject** (*what, when, where, why, how, whom*):

| Active question | Passive question |
|---|---|
| ***Why** did you beat the dog?* | ***Why** was the dog beaten by you?* |
| ***Where** did you buy this saree?* | ***Where** was this saree bought by you?* |
| ***When** will they announce the results?* | ***When** will the results be announced?* |
| ***How** did he solve the problem?* | ***How** was the problem solved by him?* |
| ***What** did she cook?* | ***What** was cooked by her?* |
| ***Whom** did you invite?* | ***Who** was invited by you?* (*whom* → *who*, because it is now the subject) |

**(b) The question word is the subject** (*who, which, what* as the doer). It becomes ***by whom*** (or *by which / by what*):

| Active question | Passive question |
|---|---|
| ***Who** wrote this poem?* | ***By whom** was this poem written?* |
| ***Who** is making that noise?* | ***By whom** is that noise being made?* |
| ***Who** has taken my pen?* | ***By whom** has my pen been taken?* |
| ***Which** team won the cup?* | ***By which** team was the cup won?* |

In modern English, *Who was this poem written by?* is also correct and more common in speech. In exams, ***By whom...?*** is the expected answer.

### Rule 5: For a command, use *Let* + object + *be* + V3.

| Active command | Passive |
|---|---|
| *Shut the door.* | ***Let** the door **be shut**.* |
| *Post the letter.* | ***Let** the letter **be posted**.* |
| *Do it now.* | ***Let** it **be done** now.* |
| *Don't touch the wires.* | ***Let** the wires **not be touched**.* (or ***Let not** the wires **be touched**.*) |
| *Let us start the game.* | ***Let** the game **be started** (by us).* |

The negative *Let ... not be* + V3 is the more modern form; *Let not ... be* + V3 is formal and older.

### Rule 6: For a request, order or advice, use *You are requested / ordered / advised* + *to*-infinitive.

Use this when the command has **no object**, or when the meaning is a request or advice. Choose the verb by the meaning.

| Active | Passive |
|---|---|
| *Please help me.* | ***You are requested to** help me.* |
| *Kindly lend me your book.* | ***You are requested to** lend me your book.* |
| *Get out!* | ***You are ordered to** get out.* |
| *Leave the room at once.* | ***You are ordered to** leave the room at once.* |
| *Take some rest.* | ***You are advised to** take some rest.* |
| *Don't smoke here.* | ***You are warned not to** smoke here.* / ***You are requested not to** smoke here.* |
| *Be quiet.* | ***You are told / ordered to** be quiet.* |

*Please* and *kindly* show a **request** → *requested*. A strong command → *ordered*. A suggestion for the listener's good → *advised*.

### Rule 7: A verb with two objects can have two passives. The person as subject is more common.

Verbs like *give, send, show, tell, offer, teach, lend, pay, promise, award, ask* can take two objects.

> *Active:* *The teacher gave **me** (indirect object) **a prize** (direct object).*

| Passive with the person as subject (more common) | Passive with the thing as subject |
|---|---|
| ***I** was given a prize by the teacher.* | ***A prize** was given **to** me by the teacher.* |
| ***She** was shown the way.* | ***The way** was shown **to** her.* |
| ***We** were taught French by Mr Kumar.* | ***French** was taught **to** us by Mr Kumar.* |

When the **thing** is the subject, add ***to*** before the person (*to me, to her*). With *buy, make, cook, find* use ***for***: *A dress was bought **for** her.*

With *buy, make, cook, find*, the person-as-subject passive is uncommon: *She was bought a dress* is possible but less natural. The *for* form is safer.

### Rule 8: Some passive verbs take a preposition other than *by*.

These verbs describe a **feeling** or a **state** more than an action. They usually take a fixed preposition.

| Passive + preposition | Example |
|---|---|
| *known **to*** | *His name is **known to** everyone.* (not *~~known by~~* for "familiar to") |
| *interested **in*** | *She is **interested in** music.* |
| *filled **with*** | *The hall was **filled with** people.* |
| *surprised **at / by*** | *We were **surprised at** the news.* |
| *pleased **with*** | *The teacher was **pleased with** our work.* |
| *satisfied **with*** | *Are you **satisfied with** the result?* |
| *covered **with / in*** | *The hills were **covered with** snow.* |
| *shocked **at / by*** | *Everyone was **shocked at** his behaviour.* |
| *disappointed **with / at / in*** | *I was **disappointed with** the film.* |
| *married **to*** | *She is **married to** a doctor.* |
| *made **of** / **from*** | *The table is **made of** wood.* / *Paper is **made from** wood.* |
| *worried **about*** | *They were **worried about** the exam.* |
| *involved **in*** | *He was **involved in** the accident.* |

> *Active:* *The news surprised us.* → *Passive:* *We were surprised **at** (or **by**) the news.*
> *Active:* *Everyone knows him.* → *Passive:* *He is known **to** everyone.*

*Made of* = the material can still be seen (wood in a table). *Made from* = the material has changed (wood into paper).

### Rule 9: Use the impersonal passive to report what people say, think or believe.

Verbs: *say, believe, think, know, report, expect, consider, suppose, allege*.

> *Active:* ***People say that** he is very rich.*

There are **two** passive forms:

| Form | Pattern | Example |
|---|---|---|
| **(a)** *It* + passive + *that* clause | *It is said that* + clause | ***It is said that** he is very rich.* |
| **(b)** Subject + passive + *to*-infinitive | *He is said to* + V1 | ***He is said to be** very rich.* |

When the reported action is **earlier** than the saying, form (b) uses the **perfect infinitive** (*to have* + V3):

> *People believe that the thief **escaped** through the window.*
> → *It is believed that the thief escaped through the window.*
> → *The thief **is believed to have escaped** through the window.*

When the saying is in the **past**:

> *People thought that she was a spy.*
> → *It **was thought** that she was a spy.*
> → *She **was thought to be** a spy.*

### Rule 10: Intransitive verbs have no passive.

A verb with **no object** cannot be made passive, even in Class 12 sentences.

> *The guests **arrived** at six.* (no object → no passive)
> *The baby **is sleeping**.* (no object → no passive)
> *Prices **have risen**.* (no object → no passive; *rise* is intransitive)

Compare *raise* (transitive): *The shopkeeper **raised** the prices.* → *The prices **were raised** by the shopkeeper.* ✔

Some verbs are intransitive in one meaning and transitive in another:

> *The bell **rang**.* (no object → no passive)
> *He **rang** the bell.* → *The bell **was rung** by him.* ✔

### Rule 11: The infinitive passive is *to be* + V3. The gerund passive is *being* + V3.

**Infinitive passive** (*to be* + V3):

> *Active:* *I want someone **to repair** my phone.*
> *Passive:* *I want my phone **to be repaired**.*
> *This work **is to be done** by tomorrow.* (= must be done)
> *There is nothing **to be afraid of**.*
> *She expects **to be selected** for the team.*

Perfect infinitive passive (*to have been* + V3): *He is said **to have been killed** in the war.*

**Gerund passive** (*being* + V3):

> *Active:* *She hates people **calling** her by her nickname.*
> *Passive:* *She hates **being called** by her nickname.*
> *I remember **being taken** to the zoo as a child.*
> *He was afraid of **being punished**.*

### Rule 12: In the passive, *make, see, hear* and *help* take *to* before the infinitive.

> *Active:* *They **made** him **wait**.* → *Passive:* *He **was made to wait**.*
> *Active:* *We **saw** her **enter** the building.* → *Passive:* *She **was seen to enter** the building.*
> *Active:* *I **heard** him **sing**.* → *Passive:* *He **was heard to sing**.*

*Let* has no normal passive. Use *be allowed to*: *They **let** me go.* → *I **was allowed to** go.*

## Special cases

### 1. Complex sentences: change the main clause, the subordinate clause, or both

> *Active:* *I know that he wrote this letter.*
> *Passive (subordinate clause):* *I know that this letter **was written** by him.*
> *Passive (both):* *It **is known** to me that this letter **was written** by him.*

In exams, changing the clause the question asks for is enough. If no clause is named, change the **main** clause, or both.

### 2. *Need* + V4 already has a passive meaning

> *The car **needs washing**.* = *The car **needs to be washed**.*

### 3. Causative: *have / get something done*

When someone else does a job for you, use *have* or *get* + object + V3.

> *I **had** my hair **cut**.* (A barber cut it.)
> *We **got** the roof **repaired**.*

### 4. Question tags with passive sentences

> *The letter was posted, **wasn't it**?*
> *The windows haven't been cleaned, **have they**?*

### 5. *By* + agent in questions

If the active question has a subject that is not a question word, keep it after *by*:

> *Did **Kavya** draw this?* → *Was this drawn **by Kavya**?*

### 6. Passive with *let's*

> *Let's sing a song.* → *Let a song **be sung** (by us).*

## Common mistakes

| Wrong | Right | Why |
|---|---|---|
| *The work must ~~be done~~ yesterday.* (meaning *Someone must have done the work yesterday*) | *The work **must have been done** yesterday.* | Modal + *have* + V3 → modal + ***have been*** + V3. |
| *~~Did~~ the letter ~~was~~ written by him?* | ***Was** the letter written by him?* | The passive has its own helping verb. Drop *did*. |
| *~~Who~~ was this poem written?* | ***By whom** was this poem written?* | *Who* was the subject (the doer) → *by whom*. |
| *~~Let~~ shut the door.* | ***Let** the door **be shut**.* | *Let* + object + *be* + V3. |
| *You are ~~requested~~ to get out!* | *You are **ordered** to get out.* | A strong command → *ordered*. |
| *A book was given ~~me~~ by him.* | *A book was given **to** me by him.* | With the thing as subject, add *to* before the person. |
| *His name is known ~~by~~ everyone.* | *His name is known **to** everyone.* | *Known* (familiar) takes *to*. |
| *The bottle is filled ~~by~~ water.* | *The bottle is filled **with** water.* | *Filled* takes *with*. |
| *He is said ~~to be stole~~ the money.* | *He is said **to have stolen** the money.* | An earlier action → perfect infinitive *to have* + V3. |
| *Prices ~~have been risen~~.* | *Prices **have risen**.* | *Rise* has no object, so no passive. |
| *He was made ~~wait~~.* | *He was made **to wait**.* | *Make* in the passive takes *to*. |
| *She hates ~~to call~~ by her nickname.* | *She hates **being called** by her nickname.* | The gerund passive is *being* + V3. |

## How it comes in the exam

Common exercise types:

- **Change the voice** of statements, questions, commands, and sentences with modals.
- **Fill in** with passive forms (including modal and infinitive passives).
- **Rewrite a process or report** in the passive.

### Steps for questions

1. **Change the question into a statement** (put the words in statement order; remove *do / does / did*).
2. **Make the statement passive** (Class 11 steps).
3. **Turn it back into a question**: question word (if any) + first helping verb + subject + rest + ?
4. **If the question word was the subject** (*who, which*), change it to ***by whom / by which*** at the start.

### Steps for commands

1. **Is there an object?**
   - Yes, and it is a plain command → ***Let*** + object + ***be*** + V3.
   - No object, or it is a request / order / advice → ***You are requested / ordered / advised to*** + V1.
2. **Negative command** → *Let ... not be* + V3, or *You are requested / warned not to...*

### Worked example 1

> *Who broke this glass?*

1. Statement: *X broke this glass.* (*Who* = the subject)
2. Passive: *This glass was broken by X.*
3. *Who* was the subject → *By whom*.

**Answer:** ***By whom was this glass broken?***

### Worked example 2

> *Why did you scold the child?*

1. Statement: *You scolded the child (for some reason).*
2. Passive: *The child was scolded by you.*
3. Question: *Why* + *was* + *the child* + *scolded by you*?

**Answer:** ***Why was the child scolded by you?***

### Worked example 3

> *Please give me a glass of water.*

1. *Please* → a request.
2. Use *You are requested to* + V1.

**Answer:** ***You are requested to give me a glass of water.*** (Also accepted: *Let a glass of water be given to me.*)

### Worked example 4

> *People believe that the temple was built in the 9th century.*

1. Reporting verb: *believe* (present). Reported action: *was built* (earlier).
2. Form (a): *It is believed that the temple was built in the 9th century.*
3. Form (b): subject *the temple* + *is believed* + perfect infinitive passive *to have been built*.

**Answer:**
- ***It is believed that the temple was built in the 9th century.***
- ***The temple is believed to have been built in the 9th century.***

### Worked example 5

> *The principal awarded Divya a gold medal.*

1. Two objects: *Divya* (person), *a gold medal* (thing).
2. Person as subject: *Divya was awarded a gold medal by the principal.*
3. Thing as subject: *A gold medal was awarded to Divya by the principal.*

**Answer:** ***Divya was awarded a gold medal by the principal.*** (or ***A gold medal was awarded to Divya by the principal.***)

### Worked example 6

> *You should have informed the police.*

1. Modal + *have* + V3 → modal + *have been* + V3.
2. Object *the police* → subject.

**Answer:** ***The police should have been informed (by you).***

## Quick check

Change into passive.

1. *Can you speak French?*
2. *Open the window.*
3. *Who has eaten my chocolate?*
4. *They say that the old house is haunted.* (two ways)
5. *The news shocked everyone.*

<details>
<summary>Show answers</summary>

1. ***Can French be spoken by you?*** Modal question → modal + subject + *be* + V3.
2. ***Let the window be opened.*** A command with an object → *Let* + object + *be* + V3.
3. ***By whom has my chocolate been eaten?*** *Who* was the subject → *By whom*. Present perfect → *has been* + V3.
4. ***It is said that the old house is haunted.*** / ***The old house is said to be haunted.*** Impersonal passive.
5. ***Everyone was shocked at (or by) the news.*** *Shocked* usually takes *at* or *by*.

</details>

## Summary

:::tip[Remember]
- Modals: modal + ***be*** + V3. Past modals: modal + ***have been*** + V3.
- Questions: statement → passive → question. *Who* (subject) → ***By whom***. *Whom* (object) → *Who*.
- Commands: ***Let*** + object + ***be*** + V3. Requests / orders / advice: ***You are requested / ordered / advised to***...
- Two objects: *I was given a book* (more common) / *A book was given **to** me*.
- *known **to**, interested **in**, filled **with**, surprised **at**, pleased **with**, made **of / from***.
- *People say...* → ***It is said that...*** / ***He is said to be...*** (earlier action: *to have been / to have* + V3).
- No object, no passive. Infinitive passive: ***to be*** + V3. Gerund passive: ***being*** + V3.
:::
