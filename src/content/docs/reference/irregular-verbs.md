A **regular verb** makes its V2 and V3 forms by adding *-ed* (walk → walked → walked). An **irregular verb** does not follow this rule. Its forms must be learned.

The verbs below are grouped by **pattern**. Learning them in groups is easier than learning one long list.

- V4 is always V1 + *-ing* (with normal spelling changes: *write → writing*, *run → running*, *lie → lying*).
- V5 is always V1 + *-s* or *-es* (*go → goes*, *catch → catches*). The only exceptions are *be → is* and *have → has*.
- Where two forms are given (*learnt / learned*), both are correct. The first is more common in British English, the second in American English.

## Verbs that are easy to confuse

| V1 | Meaning | V2 | V3 | V4 |
|---|---|---|---|---|
| lie | to rest flat | lay | lain | lying |
| lie | to say something untrue | lied | lied | lying |
| lay | to put something down | laid | laid | laying |
| rise | to go up (by itself) | rose | risen | rising |
| raise | to lift something | raised | raised | raising |
| sit | to be seated | sat | sat | sitting |
| set | to put something in place | set | set | setting |
| fall | to drop down | fell | fallen | falling |
| fell | to cut down a tree | felled | felled | felling |
| find | to discover | found | found | finding |
| found | to start (a school, a company) | founded | founded | founding |
| hang | to hang an object | hung | hung | hanging |
| hang | to put a person to death | hanged | hanged | hanging |
| wind | to turn (a clock, a road) | wound | wound | winding |
| wound | to injure | wounded | wounded | wounding |

**The quick test:** *rise*, *sit* and *lie* (to rest) never take an object. *Raise*, *set* and *lay* always do. *The sun **rises**.* / *She **raised** her hand.*
