A **question tag** is a short question at the end of a statement: *Priya is your sister, **isn't she**?*

Full lesson: [Question tags (Class 11)](/topics/t10-questions/class-11/). Practice: [Practice: question tags](/topics/t10-questions/class-11-practice/).

## The five main rules

| # | Rule | Example |
|---|---|---|
| 1 | Positive statement → negative tag. Negative statement → positive tag. | *She is a doctor, **isn't she**?* / *She isn't a doctor, **is she**?* |
| 2 | Use the same helping verb as the statement. If there are two or more, use the first. | *Kavya **has** finished, **hasn't** she?* / *He **has** been working, **hasn't** he?* |
| 3 | No helping verb → use *do / does / did* (*does* for V5, *do* for V1, *did* for V2). | *Arun plays cricket, **doesn't** he?* / *They live in Salem, **don't** they?* / *Meena went home, **didn't** she?* |
| 4 | Use a pronoun in the tag, never the noun. *This / that* → *it*; *these / those* → *they*. | *Ravi is tall, isn't **he**?* / *This is your bag, isn't **it**?* |
| 5 | A negative tag uses the short form (*n't*). | *She is coming, **isn't** she?* (not *~~is not she~~*) |

## Every special case

| Statement type | Tag | Example |
|---|---|---|
| *I am* (positive) | ***aren't I?*** | *I am late, **aren't I**?* |
| *I am not* | ***am I?*** | *I'm not late, **am I**?* |
| *Let's* (suggestion) | ***shall we?*** | *Let's go for a walk, **shall we**?* |
| *Let us* (= allow us; a request) | ***will you?*** | *Let us go home early, **will you**?* |
| Command / request (positive) | ***will you?*** (also *won't you? / can you? / could you?*) | *Close the door, **will you**?* / *Have a sweet, **won't you**?* |
| Negative command (*Don't ...*) | ***will you?*** | *Don't be late, **will you**?* |
| *There is / there are / there was* | *isn't there? / aren't there? / wasn't there?* | *There is a bank nearby, **isn't there**?* |
| *There isn't / there aren't* | *is there? / are there?* | *There isn't any milk, **is there**?* |
| *everyone, everybody, someone, somebody, anyone, no one, nobody* | ***they*** | *Everyone enjoyed it, didn't **they**?* / *Nobody came, did **they**?* |
| *everything, something, anything, nothing* | ***it*** | *Everything is ready, isn't **it**?* / *Nothing happened, did **it**?* |
| *never, no, nobody, nothing, none, nowhere, hardly, scarcely, barely, seldom, rarely, few, little* | **positive** tag | *He never lies, **does** he?* / *Few came, **did** they?* / *There's little time, **is** there?* |
| *a few, a little* (positive meaning) | **negative** tag | *A few came, **didn't** they?* / *There's a little time, **isn't** there?* |
| *have* as a helping verb (+ V3) | *haven't / hasn't / hadn't* | *She has finished, **hasn't** she?* |
| *have* as a main verb (own, eat, take) | *don't / doesn't / didn't* (British also *hasn't / haven't*) | *She has a new phone, **doesn't** she?* / *They had lunch, **didn't** they?* |
| *had better* | ***hadn't*** | *You had better go, **hadn't** you?* |
| *used to* | ***didn't*** | *He used to live here, **didn't** he?* |
| *ought to* | ***shouldn't*** (also *oughtn't*, formal) | *We ought to help, **shouldn't** we?* |
| *must* (obligation) | ***mustn't*** | *You must go, **mustn't** you?* |
| *must* (deduction: "I'm sure") | the verb the speaker is sure about | *He must be tired, **isn't** he?* |
| Two clauses (main + subordinate) | match the **main** clause | *He said that he was tired, **didn't** he?* |
| *I think / I believe / I suppose / I'm sure* + clause | match the **second** clause | *I think she is right, **isn't she**?* |
| *will* | ***won't*** | *You will come, **won't** you?* |
| *can* | ***can't*** | *You can swim, **can't** you?* |

## How to say it

| Tone | Meaning | Example |
|---|---|---|
| Falling ↘ | I'm sure; please agree | *It's a lovely day, isn't it?* ↘ |
| Rising ↗ | I'm not sure; please tell me | *You've paid the fees, haven't you?* ↗ |

## The four-step method

1. **Positive or negative?** Look for *not / n't* and negative words (*never, hardly, nobody, few...*).
2. **Which helping verb?** None → *do / does / did*.
3. **What is the subject?** Change it to a pronoun.
4. **Build the tag:** comma + helping verb (with *n't* if negative) + pronoun + ?

Then check the special cases: *I am, Let's,* commands, *there, everyone / nothing, I think.*
