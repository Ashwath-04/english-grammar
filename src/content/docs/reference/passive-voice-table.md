**The rule:** the object of the active sentence becomes the subject. The verb becomes ***be* (in the same tense) + V3**. The old subject goes after ***by*** (or is left out if it is *someone, people, they*).

> *Active:* ***Kavya** writes **a letter**.* → *Passive:* ***A letter** is written by **Kavya**.*

Full lessons: [Active and passive voice (Class 11)](/topics/t11-active-passive/class-11/) and [Class 12](/topics/t11-active-passive/class-12/).

## Tenses

The examples use *She* + *write* + *a letter*.

| Tense | Active | Passive formula | Passive |
|---|---|---|---|
| Present simple | *She writes a letter.* | *am / is / are* + V3 | *A letter **is written** by her.* |
| Present continuous | *She is writing a letter.* | *am / is / are being* + V3 | *A letter **is being written** by her.* |
| Present perfect | *She has written a letter.* | *has / have been* + V3 | *A letter **has been written** by her.* |
| Present perfect continuous | *She has been writing a letter.* | — | not normally used |
| Past simple | *She wrote a letter.* | *was / were* + V3 | *A letter **was written** by her.* |
| Past continuous | *She was writing a letter.* | *was / were being* + V3 | *A letter **was being written** by her.* |
| Past perfect | *She had written a letter.* | *had been* + V3 | *A letter **had been written** by her.* |
| Past perfect continuous | *She had been writing a letter.* | — | not normally used |
| Future simple | *She will write a letter.* | *will / shall be* + V3 | *A letter **will be written** by her.* |
| Future continuous | *She will be writing a letter.* | — | not normally used |
| Future perfect | *She will have written a letter.* | *will / shall have been* + V3 | *A letter **will have been written** by her.* |
| Future perfect continuous | *She will have been writing a letter.* | — | not normally used |
| *be going to* | *She is going to write a letter.* | *am / is / are going to be* + V3 | *A letter **is going to be written** by her.* |

**Negative:** *not* after the first helping verb: *A letter **was not** written.* / *A letter **has not been** written.*

## Modals

| Active | Passive formula | Passive |
|---|---|---|
| *You can solve it.* | modal + *be* + V3 | *It **can be solved**.* |
| *We must finish the work.* | modal + *be* + V3 | *The work **must be finished**.* |
| *You should help the poor.* | modal + *be* + V3 | *The poor **should be helped**.* |
| *He ought to obey the rules.* | *ought to be* + V3 | *The rules **ought to be obeyed**.* |
| *You have to wear a uniform.* | *have to be* + V3 | *A uniform **has to be worn**.* |
| *Someone must have stolen it.* | modal + *have been* + V3 | *It **must have been stolen**.* |
| *You should have told me.* | modal + *have been* + V3 | *I **should have been told**.* |

## Questions

| Active | Passive |
|---|---|
| *Did he write the letter?* | ***Was** the letter written by him?* |
| *Does she sing songs?* | ***Are** songs sung by her?* |
| *Is Ravi cooking dinner?* | ***Is** dinner being cooked by Ravi?* |
| *Have you finished the work?* | ***Has** the work been finished by you?* |
| *Will they invite us?* | ***Will** we be invited by them?* |
| *Can you lift this box?* | ***Can** this box be lifted by you?* |
| *Who wrote this poem?* | ***By whom** was this poem written?* |
| *Who is making the noise?* | ***By whom** is the noise being made?* |
| *Whom did you invite?* | ***Who** was invited by you?* |
| *What did she cook?* | ***What** was cooked by her?* |
| *Why did you beat the dog?* | ***Why** was the dog beaten by you?* |
| *When will they announce the result?* | ***When** will the result be announced?* |

**Method:** question → statement → passive → question again. The *do / does / did* of the active question disappears.

## Commands and requests

| Active | Passive |
|---|---|
| *Shut the door.* | ***Let** the door **be shut**.* |
| *Post this letter.* | ***Let** this letter **be posted**.* |
| *Don't waste food.* | ***Let** food **not be wasted**.* / *Let not food be wasted.* (formal) |
| *Let us start the game.* | ***Let** the game **be started** (by us).* |
| *Please help me.* | ***You are requested to** help me.* |
| *Get out!* | ***You are ordered to** get out.* |
| *Take your medicine on time.* | ***You are advised to** take your medicine on time.* |
| *Don't smoke here.* | ***You are warned / requested not to** smoke here.* |

## Two objects

| Active | Passive (person as subject) | Passive (thing as subject) |
|---|---|---|
| *He gave me a book.* | ***I** was given a book.* | ***A book** was given **to** me.* |
| *She showed us the way.* | ***We** were shown the way.* | ***The way** was shown **to** us.* |
| *Mr Kumar teaches us maths.* | ***We** are taught maths by Mr Kumar.* | ***Maths** is taught **to** us by Mr Kumar.* |
| *My aunt bought me a dress.* | (less natural) | ***A dress** was bought **for** me.* |

## Impersonal passive

| Active | Passive (*It ... that*) | Passive (subject + *to*) |
|---|---|---|
| *People say that he is rich.* | ***It is said that** he is rich.* | *He **is said to be** rich.* |
| *People believe that she stole it.* | ***It is believed that** she stole it.* | *She **is believed to have stolen** it.* |
| *They thought that he was a spy.* | ***It was thought that** he was a spy.* | *He **was thought to be** a spy.* |

## Infinitives, gerunds and verbs of perception

| Active | Passive |
|---|---|
| *I want someone to repair my phone.* | *I want my phone **to be repaired**.* |
| *She hates people teasing her.* | *She hates **being teased**.* |
| *They made him wait.* | *He **was made to wait**.* |
| *We saw her enter.* | *She **was seen to enter**.* |
| *They let me go.* | *I **was allowed to** go.* |

## Agents other than *by*

| Passive + preposition | Example |
|---|---|
| *known to* | *He is known **to** everyone.* |
| *interested in* | *She is interested **in** music.* |
| *filled with* | *The hall was filled **with** people.* |
| *surprised at / by* | *We were surprised **at** the news.* |
| *pleased with* | *The teacher was pleased **with** us.* |
| *covered with / in* | *The hills are covered **with** snow.* |
| *made of / from* | *made **of** wood* (still wood) / *made **from** wood* (changed, e.g. paper) |

## Remember

- **No object, no passive:** *arrive, sleep, go, rise, happen* have no passive.
- Pronouns: *I → me, we → us, he → him, she → her, they → them* after *by*.
- Leave out *by someone, by people, by them* (people in general).
- Phrasal verbs keep their small word: *The baby was looked **after**.*
