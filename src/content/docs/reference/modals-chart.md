**Modal auxiliaries** (*can, could, may, might, will, would, shall, should, must, ought to*) are always followed by **V1**. They never take *-s*, and they make their own questions and negatives (*Can he ...? He cannot ...*).

To talk about the **past**, most modals use **modal + *have* + V3** (*must have gone, should have told*). Some use a different word (*must → had to*).

Full lessons: [Modal auxiliaries (Class 11)](/topics/t02-modal-auxiliaries/class-11/) and [Modal auxiliaries (Class 12)](/topics/t02-modal-auxiliaries/class-12/).

## Modals by function

| Function | Present / future | Past | Example (present) | Example (past) |
|---|---|---|---|---|
| **Ability** | *can, am / is / are able to* | *could* (general), *was / were able to* (one success) | *Kavya **can** swim.* | *She **could** swim at five.* / *She **was able to** escape.* |
| **Future ability** | *will be able to* | — | *You **will be able to** drive soon.* | — |
| **Unused past ability** | — | *could have* + V3 | — | *You **could have** won.* (but you didn't) |
| **Permission** (asking) | *may* (formal), *can*, *could* (polite) | *was / were allowed to* | ***May** I come in?* | *We **were allowed to** leave early.* |
| **Permission** (giving) | *may, can* | *could* (general) | *You **may** go.* | *We **could** stay up late on Sundays.* |
| **Possibility** | *may, might, could* | *may have, might have, could have* + V3 | *It **may** rain.* | *He **may have** missed the bus.* |
| **Deduction: sure (yes)** | *must* | *must have* + V3 | *She **must** be tired.* | *It **must have** rained.* |
| **Deduction: sure (no)** | *can't, couldn't* | *can't have, couldn't have* + V3 | *That **can't** be Ravi.* | *He **can't have** seen me.* |
| **Obligation / necessity** | *must* (speaker's view), *have to / has to* (from outside), *need to* | *had to* | *You **must** wear a helmet.* | *I **had to** wait an hour.* |
| **Future obligation** | *will have to* | — | *You **will have to** pay a fine.* | — |
| **Prohibition** | *must not, cannot, may not* | *was / were not allowed to* | *You **mustn't** smoke here.* | *We **weren't allowed to** use phones.* |
| **No necessity** | *need not, don't have to, don't need to* | *didn't have to / didn't need to* (maybe not done); *needn't have* + V3 (done, but not necessary) | *You **needn't** come.* | *You **needn't have** cooked.* |
| **Advice** | *should, ought to, had better* | *should have, ought to have* + V3 (not done: criticism / regret) | *You **should** rest.* | *You **should have** told me.* |
| **Criticism of an action done** | — | *shouldn't have, oughtn't to have* + V3 | — | *You **shouldn't have** shouted.* |
| **Request** | *can, could, will, would* | — | ***Could** you help me?* | — |
| **Offer** | *shall I, can I, I will* | — | ***Shall** I carry this?* | — |
| **Suggestion** | *shall we, let's, could* | *could have* + V3 | ***Shall** we go?* | *We **could have** taken a taxi.* |
| **Willingness / refusal** | *will, won't* | *would, wouldn't* | *I **will** help.* / *He **won't** listen.* | *He **wouldn't** listen.* |
| **Promise / determination** | *will, shall* (formal) | *would* (reported) | *I **will** pass!* | *She said she **would** pass.* |
| **Past habit** | — | *used to* (actions and states), *would* (actions only) | — | *We **used to** live in Salem.* / *He **would** tell stories.* |
| **Imaginary result** (conditionals) | *would, could, might* | *would have, could have, might have* + V3 | *I **would** travel if I were rich.* | *I **would have** come if I had known.* |
| **Expectation** | *should*, *be supposed to* | *was / were supposed to* | *The bus **should** be here soon.* | *It **was supposed to** arrive at 6.* |
| **Daring** | *dare (not)* | *dared (not)* | *He **dare not** speak.* | *She **dared not** ask.* |

## The four features of modals

| Feature | Right | Wrong |
|---|---|---|
| Followed by V1 | *She can **sing**.* | *~~She can sings / can to sing.~~* |
| No *-s* with *he / she / it* | *He **must** go.* | *~~He musts go.~~* |
| Own negative and question | *You **should not** go.* / ***Can** he swim?* | *~~You don't should go.~~* / *~~Does he can swim?~~* |
| No *-ing*, no *to*, no V3 form | *I **will be able to** come.* | *~~I will can come.~~* |

*Ought to* is the one modal followed by *to*: *You **ought to** respect elders.*

## The pairs that are easy to confuse

| Pair | Difference |
|---|---|
| *must* / *have to* | *must* = the speaker's own feeling or rule; *have to* = a rule or need from outside. Past of both: *had to*. |
| *mustn't* / *needn't* | *mustn't* = don't do it (not allowed). *needn't* = it is not necessary (you may choose). |
| *needn't have* + V3 / *didn't need to* | *needn't have* = done, but not necessary. *didn't need to* = not necessary (usually not done). |
| *could* / *was able to* | General past ability: both. One particular past success: *was able to*. |
| *may* / *might* | *Might* is a little less sure. *Might* is used after a past reporting verb. |
| *will* / *shall* | *Will* for all persons. *Shall* with *I / we* for offers and suggestions (*Shall I ...? Shall we ...?*), and in formal rules. |
| *used to* / *be used to* | *used to* + V1 = a past habit. *be used to* + V4 = accustomed to. |
