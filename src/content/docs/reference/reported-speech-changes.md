## Tense changes (when the reporting verb is in the past)

| Direct speech | Reported speech | Example |
|---|---|---|
| present simple | past simple | *"I **live** here."* → *he **lived** there* |
| present continuous | past continuous | *"I **am working**."* → *she **was working*** |
| present perfect | past perfect | *"I **have seen** it."* → *he **had seen** it* |
| present perfect continuous | past perfect continuous | *"I **have been waiting**."* → *she **had been waiting*** |
| past simple | past perfect (or no change) | *"I **saw** him."* → *he **had seen** him* |
| past continuous | past perfect continuous | *"I **was sleeping**."* → *she **had been sleeping*** |
| past perfect | no change | *"I **had left**."* → *he **had left*** |
| *will* | *would* | *"I **will** go."* → *she **would** go* |
| *shall* | *should* / *would* | *"I **shall** come."* → *he **should / would** come* |
| *can* | *could* | *"I **can** swim."* → *he **could** swim* |
| *may* | *might* | *"I **may** be late."* → *she **might** be late* |
| *must* (necessity) | *had to* (or *must*) | *"I **must** go."* → *he **had to** go* |
| *could, would, should, might, ought to, must* (deduction) | no change | *"You **should** rest."* → *I **should** rest* |

**No tense change when:**
- the reporting verb is in the present or future (*says, will say, has said*)
- the speech is a universal truth or scientific fact (*The earth **goes** round the sun.*)
- (optional) the fact is still true: *He said he **lives** / **lived** in Salem.*

## Pronoun changes

| In direct speech | Changes to match |
|---|---|
| 1st person: *I, me, my, mine, we, us, our* | the **speaker** (the subject of the reporting verb) |
| 2nd person: *you, your, yours* | the **listener** (the object of the reporting verb) |
| 3rd person: *he, she, it, they* | **no change** |

> *Ravi said to Priya, "**I** will help **you**."* → *Ravi told Priya that **he** would help **her**.*

## Time and place changes

| Direct | Reported |
|---|---|
| now | then / at that time |
| today | that day |
| tonight | that night |
| this morning / week / year | that morning / week / year |
| tomorrow | the next day / the following day |
| yesterday | the previous day / the day before |
| next week / month / year | the following week / month / year |
| last week / month / year | the previous week / the week before |
| (two days) ago | (two days) before / earlier |
| here | there |
| this | that |
| these | those |
| come | go (when *here* becomes *there*) |

These changes follow logic. If the report is made the same day in the same place, *today* and *here* can stay.

## Reporting verb by sentence type

| Kind of sentence | Reporting verb | Joining word | Example |
|---|---|---|---|
| Statement | *said* / *told* + person | *that* | *She **told** me **that** she was busy.* |
| Yes/no question | *asked, enquired, wanted to know* | *if / whether* | *He **asked if** I was ready.* |
| Wh- question | *asked, enquired, wanted to know* | the question word | *She **asked where** I lived.* |
| Command | *told, ordered, commanded* + person | *to* / *not to* + V1 | *He **ordered** them **to** stop.* |
| Request (*please*) | *requested, begged* + person | *to* / *not to* + V1 | *She **requested** me **to** help.* |
| Advice | *advised* + person | *to* / *not to* + V1 | *The doctor **advised** him **to** rest.* |
| Warning | *warned* + person | *to* / *not to* + V1 | *She **warned** me **not to** touch it.* |
| Exclamation | *exclaimed (with joy / sorrow / surprise)* | *that* | *He **exclaimed with joy that** they had won.* |
| Wish / prayer | *wished, prayed* | — / *that* | *She **prayed that** God might bless me.* |
| Greeting | *wished, greeted, bade* | — | *He **wished** me good morning.* |
| *Let's* | *suggested, proposed* | *that* ... *should* / + V4 | *He **suggested that** we **should** go.* |
| *Shall I ...?* (offer) | *offered* | *to* + V1 | *He **offered to** help.* |
| *Will you ...?* (request) | *requested, asked* + person | *to* + V1 | *She **requested** me **to** wait.* |

## Precise reporting verbs and their patterns

| Verb | Pattern | Example |
|---|---|---|
| suggested | *that* + *should* + V1 / + V4 | *suggested **that we should go*** / *suggested **going*** |
| apologised | (*to* + person) *for* + V4 | *apologised **for being** late* |
| promised | *to* + V1 / *that* ... *would* | *promised **to come*** |
| refused | *to* + V1 | *refused **to sign*** |
| agreed | *to* + V1 / *that* | *agreed **to help*** |
| offered | *to* + V1 | *offered **to carry** the bag* |
| threatened | *to* + V1 | *threatened **to leave*** |
| admitted | V4 / *that* | *admitted **taking** it* |
| denied | V4 / *that* | *denied **breaking** it* |
| reminded | person + *to* + V1 | *reminded me **to call*** |
| invited | person + *to* + V1 | *invited us **to stay*** |
| congratulated | person + *on* + noun / V4 | *congratulated her **on winning*** |
| thanked | person + *for* + noun / V4 | *thanked us **for helping*** |
| accused | person + *of* + V4 | *accused him **of lying*** |
| insisted | *on* + V4 / *that* | *insisted **on paying*** |
| complained | *that* / *about* + noun | *complained **that** the food was cold* |

## Word order and punctuation

- Reported questions use **statement order**: *She asked where **I lived*** (not *~~where did I live~~*).
- No *do / does / did* in reported questions.
- No question mark and no quotation marks: end with a full stop.
- No *that* before *if, whether* or a question word.
- *said* + *that*; never *~~said me~~*. *told* + person; never *~~told that~~*.
